# gearscore_binary
Program to check WM's Icecrown character(gear, GS, ench/gems, achievs).

> [!WARNING]
> Only binary file.

Download zip, unzip and run in command line (cmd.exe).  
         
**Use:** charact.exe name     
**Example:** charact.exe Myexamplecom
